# Leads sem site — Jardim Botânico

Mapa de negócios **ativos** no Jardim Botânico, Porto Alegre, que têm identidade própria e **não têm site oficial**. O recorte existe para priorizar conversão: casas que já têm nome, ponto e movimento, e ainda entregam o clique para Instagram, iFood ou diretório de terceiro.

Pesquisa feita em **2 de setembro de 2026**, com fontes públicas (Google/guias, Comida di Buteco, listagens de rua e checagem de domínio).

## Como rodar

```bash
npm install
npm run dev
```

O app sobe em [http://127.0.0.1:43127](http://127.0.0.1:43127).

## O que está dentro

- 12 leads qualificáveis, com score, telefone/WhatsApp quando público, lacuna digital e pitch de abordagem
- Filtro por ofício e prioridade
- Lista do que ficou de fora (já tem site, rede ou ponto inativo)
- Critérios da pesquisa no rodapé do painel

## Critérios

1. Ponto no Jardim Botânico ou na borda imediata
2. Sinal de operação recente
3. Identidade sólida (nome, prêmio, tempo de casa ou ofício raro)
4. Sem site oficial no ar
5. Perfil que ganha com site (cardápio, agenda, orçamento, portfólio)

Confirme no balcão antes de fechar proposta: listagens públicas atrasam, e um domínio morto pode ter sido religado depois desta pesquisa.
