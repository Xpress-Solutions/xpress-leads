# Xpress Leads — RMPA sem site

Mapa de negócios **ativos** na Região Metropolitana de Porto Alegre (capital, Canoas, Gravataí, Novo Hamburgo e São Leopoldo) que têm identidade própria e **não têm site oficial**. O recorte prioriza conversão: casas com nome, ponto e movimento, que ainda entregam o clique para Instagram, iFood, Booksy ou diretório de terceiro. Sem negócio repetido.

Pesquisa feita em **2 de setembro de 2026**, com fontes públicas (Google/guias, Comida di Buteco 2026, Booksy, CNPJ e checagem de domínio).

## Como rodar

```bash
npm install
npm run build
npm start -- --port 43127
```

O app sobe em [http://127.0.0.1:43127](http://127.0.0.1:43127).

## O que está dentro

- Dezenas de leads qualificáveis, com cidade, bairro, score, telefone/WhatsApp quando público, lacuna digital e pitch de abordagem
- Filtros por cidade, bairro, ofício e prioridade
- Lista do que ficou de fora (já tem site, rede ou ponto inativo)
- Critérios da pesquisa no painel

## Critérios

1. Ponto em Porto Alegre ou na RMPA (Canoas, Gravataí, Novo Hamburgo, São Leopoldo)
2. Sinal de operação recente (concurso 2026, avaliações/agenda ativas, CNPJ regular)
3. Identidade sólida (nome, prêmio, tempo de casa ou ofício raro)
4. Sem site oficial no ar
5. Perfil que ganha com site (cardápio, agenda, reserva, agendamento)

Confirme no balcão antes de fechar proposta: listagens públicas atrasam, e um domínio morto pode ter sido religado depois desta pesquisa.
