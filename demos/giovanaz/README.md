# Churrascaria Giovanaz — demo

One-page da casa na Av. Venâncio Aires, 10 (Cidade Baixa, Porto Alegre).

Identidade extraída da fachada real: letreiro branco com **GIOVANAZ** em vermelho sinal, poster amarelo de espeto corrido, salão de toalha e forro de madeira. Ver `brand.json`.

```bash
npm install
npm run dev
npm run build
```
