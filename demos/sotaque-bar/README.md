# Sotaque Bar — demo

One-page do **Sotaque Bar** (Av. Protásio Alves, 699 · Rio Branco · Porto Alegre).

A pele vem de `brand.json`: fachada verde-musgo, lima da marquise, letreiro geométrico e janelões da esquina. Fotos do projeto da Butiá Arquitetura (Roberta Gewehr).

```bash
npm install
npm run dev
npm run build
```

Sem deploy na Vercel.
