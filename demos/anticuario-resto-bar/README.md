# Anticuário Restô Bar — demo

One-page da fábrica Xpress para o restô-bar uruguaio da Lima e Silva, Cidade Baixa, Porto Alegre.

Identidade em `brand.json` (schema `lib/brand.ts`): script dourado no preto, listras Peñarol, xadrez vermelho, celeste da bandeira, salão-antiquário.

```bash
npm install
npm run dev
npm run build
```

Sem deploy na Vercel.
