# Anticuário Restô Bar — demo

One-page da casa na Lima e Silva, 985, Cidade Baixa, Porto Alegre.

Identidade em `brand.json` (ouro cursivo do letreiro, madeira de noite, vermelho da toalha xadrez). Fotos públicas da fachada, do salão e dos pratos.

```bash
npm install
npm run dev
npm run build
```
