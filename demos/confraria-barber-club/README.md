# Confraria Barber Club

One-page da barbearia da Cidade Baixa (Rua José do Patrocínio, 378).

Identidade extraída do logo Booksy, da fachada com toldo listrado, do interior de cimento queimado e do cartaz **Bruxos / Amigos da Confraria**. Contrato visual em `brand.json`.

```bash
npm install
npm run dev
npm run build
```

Sem deploy na Vercel neste lote.
