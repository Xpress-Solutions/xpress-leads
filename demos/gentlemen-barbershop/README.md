# Gentlemen's BarberShop — demo

One-page da barbearia da Rua Félix da Cunha, 657 (Floresta, Porto Alegre).

Identidade extraída do logo e das fotos oficiais no Booksy + Instagram `@gentlemen.s_barbershop`: parede ardósia, piso xadrez, badge cinza com cartola/bigode e aro bronze — **não** o clichê navy/gold.

```bash
npm install
npm run dev
npm run build
```

`brand.json` segue o schema `BrandIdentity` em `lib/brand.ts`.
