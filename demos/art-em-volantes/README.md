# Art em Volantes — demo Xpress

One-page do ateliê de revestimento de volantes no Jardim Botânico (Porto Alegre). Identidade extraída do logo amarelo-preto, das fotos oficiais de couro/costura e do ponto na Barão do Amazonas, 1475.

```bash
npm install
npm run dev
npm run build
```

Brand: `brand.json` (schema `BrandIdentity` em `lib/brand.ts`).
