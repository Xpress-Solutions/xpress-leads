# Churrascaria Roda de Carreta — demo

One-page da fábrica Xpress para o lead `roda-de-carreta`.

Identidade em `brand.json` (schema `BrandIdentity`). Cores, tipografia e voz vêm da fachada de toras do 35 CTG, dos lustres-roda, do lenço vermelho da invernada e do logo circular no peito do garçom.

```bash
npm install
npm run dev
npm run build
```
