# Niramaki Sushi — demo Xpress

One-page do lead `niramaki-sushi` (Jardim Botânico, Porto Alegre).

Identidade em `brand.json`. Cores, tipografia e voz saem do logo oficial, do cardápio em [niramaki.ola.click](https://niramaki.ola.click/) e das avaliações locais.

```bash
npm install
npm run dev
npm run build
```
