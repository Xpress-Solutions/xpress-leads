# Andboy Barber Shop — demo

One-page da casa do Andboy na Cruz Jobim, 623 (Jardim Itu, Porto Alegre).

Identidade extraída do logo e das fotos oficiais no Booksy: charcoal, branco, vermelho de poste, navalhas cruzadas, tijolo e o barbeiro na cadeira. Ver `brand.json`.

```bash
npm install
npm run dev
npm run build
```

Não é deploy de produção. Apresentação demonstrativa Xpress.
