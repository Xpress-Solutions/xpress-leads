# Golden Bull — demo de site

One-page do bar na Rua Cipó, 1264, Passo D’Areia, Porto Alegre.

Identidade em `brand.json` (schema `BrandIdentity`). Cores lidas da foto oficial da Bruscheta Golden (Israh Ramos / Sabores do Sul) + nome Golden Bull + horário noturno.

```bash
npm install
npm run dev
npm run build
```
