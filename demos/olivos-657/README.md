# Olivos 657 — demo

One-page do gastrobar intimista na Rua da República, 657, Cidade Baixa, Porto Alegre.

Identidade em `brand.json` (`BrandIdentity` / `lib/brand.ts` do repo). Não é tema genérico Xpress nem pele de boteco.

```bash
npm install
npm run dev
```

Build: `npm run build`. Sem deploy na Vercel.
