# Barbearia Strong — demo

One-page da casa da Rua Dr. Flores, 327 loja 3 (Centro Histórico, Porto Alegre).

Identidade extraída do Instagram oficial [@barbeariastrongpoa](https://www.instagram.com/barbeariastrongpoa/) e fotos públicas: logo circular P&B com bigode, parede de tijolo, voz do Anderson.

```bash
npm install
npm run dev
npm run build
```

Não faz deploy automático. Brand em `brand.json`.
