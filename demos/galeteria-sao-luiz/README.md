# Galeteria São Luiz — demo

One-page da casa em Santana (Porto Alegre), calibrada com o `brand.json`.

- Identidade: letreiro vermelho + faixa amarela da fachada, logo do espeto, almoço desde 1988
- Cores oficiais do Cardápio Web: `--brand: #b10606`
- Fotos: fachada, salão, galeto e buffet da própria casa (Restaurant Guru + logo oficial)

```bash
npm install
npm run dev
npm run build
```

Não é deploy. Branch da fábrica: `demo/galeteria-sao-luiz-d6be`.
