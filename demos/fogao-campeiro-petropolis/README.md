# Fogão Campeiro Petrópolis

One-page de almoço campeiro no casarão da Av. Lageado, 1265.

Identidade em `brand.json` (schema `BrandIdentity` de `lib/brand.ts`): verde-limão e azul-real da fachada JC, xadrez preto-e-branco do acesso, lousa “campeira e caseira”, tipografia de casarão.

```bash
npm install
npm run dev
npm run build
```
