# Fogão Campeiro Petrópolis

One-page de almoço campeiro no casarão da Av. Lageado, 1265.

Identidade em `brand.json` (schema `BrandIdentity` de `lib/brand.ts`): logo oficial do letreiro (panela + cursivo), verde-limão e azul-real da fachada JC, xadrez da escada do 1265, lousa “campeira e caseira”, tipografia de casarão.

```bash
npm install
npm run dev
npm run build
```

Sem deploy Vercel nesta branch.
