# Pinhos Botecaria Pub — demo

One-page da fábrica Xpress para o lead `pinhos-botecaria` (Canoas).

- Identidade em `brand.json` (pilar mostarda, blackletter, laranja de reserva)

```bash
npm install

npm run build
```
