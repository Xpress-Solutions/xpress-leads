# Oficina Mecânica Guime — demo

One-page da fábrica Xpress para o lead `mecanica-guime`.

Identidade em [`brand.json`](./brand.json). Copy de `data/leads.ts`. Visual calibrado contra Boteco Vitória (escuro, denso) e Armazém Anita (casa de bairro) — pele própria: piso de oficina, amarelo de sinalização, azul de ferramenta.

```bash
npm install
npm run dev
npm run build
```
