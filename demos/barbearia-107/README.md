# Barbearia 107 — demo

One-page da marca **107** (Barro Vermelho, Gravataí). Combos, Fabricio Brasil, WhatsApp e agenda.

## Marca

Cores e voz em `brand.json` (schema `lib/brand.ts`). Extraídas do logo oficial (gorila gentleman) e da capa Booksy (amarelo asfalto `#FCC624` + preto).

```bash
npm install
npm run dev
npm run build
```
