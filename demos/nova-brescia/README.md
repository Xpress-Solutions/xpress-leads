# Lanches Nova Bréscia — demo

One-page da lancheria de xis na Av. São Pedro, 1359, São Geraldo, Porto Alegre.

Identidade visual extraída da fachada real (toldo vermelho, letreiro branco, filete verde, azulejo bege) e gravada em `brand.json`.

```bash
npm install
npm run dev
npm run build
```

Fotos da casa: visita publicada pela TVS Play (fev/2026), usadas só nesta demo da própria lancheria.
