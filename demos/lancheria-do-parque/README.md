# Lancheria do Parque — demo

One-page da Lanchera (Av. Osvaldo Aranha, 1086, Bom Fim, Porto Alegre).

Identidade em `brand.json` (toldo vermelho, suco na jarra, letreiro branco). Fotos reais da casa via Wikimedia Commons (CC BY-SA 4.0, Hedestad) — ver `public/credits.txt`.

```bash
npm install
npm run dev
npm run build
```

Apresentação demonstrativa. Sem deploy.
