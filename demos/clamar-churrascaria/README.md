# Clamar Churrascaria — demo

One-page da churrascaria de avenida no **1044 da Azenha**, Porto Alegre.

Identidade em `brand.json` (`BrandIdentity` em `lib/brand.ts`). Cores vêm da fachada ocre da Azenha + letreiro cream + salão escuro — não de um tema gaúcho genérico.

```bash
npm install
npm run dev
npm run build
```

Sem deploy na Vercel neste lote.
