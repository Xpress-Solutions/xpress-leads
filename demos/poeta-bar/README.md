# Poeta Bar — demo

One-page do Poeta Bar (Rua dos Andradas / Rua da Praia, Centro Histórico, Porto Alegre).

Identidade em `brand.json` (schema `BrandIdentity` em `lib/brand.ts`): oliva, tijolo e ocre do logo oficial @poetabarbr; serifada Fraunces no nome; Cocó Crispy em destaque.

```bash
npm install
npm run dev
npm run build
```
