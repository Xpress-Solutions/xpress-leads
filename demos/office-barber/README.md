# Office Barber — demo

One-page da barbearia na Rua Barão do Amazonas, 1173 (loja térreo), Jardim Botânico / Porto Alegre.

Identidade extraída do selo oficial e das fotos do [Booksy](https://booksy.com/pt-br/232615_officebarber_barbearias_804125_porto-alegre): preto, ouro da camiseta, interior de bloco cinza e vitrine de rua.

```bash
npm install
npm run dev
npm run build
```

Não é deploy de produção. Apresentação demonstrativa Xpress.
